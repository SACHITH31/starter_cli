# starter-cli

A simple CLI tool to quickly create full stack starter projects.

## Features

- HTML / CSS / JavaScript starter
- React.js starter using Vite
- Node.js backend using Express
- Automatic starter files and folder structure

## Run locally

```bash
npm install
node bin/index.js

After that:

git add .
git commit -m "Add README"
```

```bash
shortcuts:
- starter
- starter my-app
- starter my-app --react
- starter my-app --html
- starter my-app --react --node
- starter my-app --html --node
- starter --help
- starter --version
